# NetCorte

App Android (Kotlin) con botón flotante que corta todo el tráfico de internet (VPN local "agujero negro") y lo restaura al instante.

## Compilar el APK en GitHub
1. Crea un repositorio y sube TODO el contenido de esta carpeta (incluida `.github`).
2. Ve a la pestaña **Actions** → "Build APK" (corre solo en cada push, o pulsa *Run workflow*).
3. Al terminar, abre la ejecución y descarga **NetCorte-apk** (contiene `app-release.apk`).
4. Instálalo en el teléfono (permite instalar apps de origen desconocido).

## Primer uso
1. Abre la app → **Permitir mostrar sobre otras apps**.
2. **Autorizar conexión VPN**.
3. **Mostrar botón flotante** → toca el círculo para cortar / restaurar. Arrástralo para moverlo.
